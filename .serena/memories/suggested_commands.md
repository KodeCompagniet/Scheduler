# Suggested Commands
- Build everything: `dotnet build DemiCode.Scheduling.sln`
- Run all tests: `dotnet test DemiCode.Scheduling.sln`
- Restore packages (if needed): `dotnet restore DemiCode.Scheduling.sln`
- Run sample console (replace project as needed): `dotnet run --project Samples/SampleConsole/SampleConsole.csproj`
- Format via dotnet-format (install first, if available): `dotnet format DemiCode.Scheduling.sln`
